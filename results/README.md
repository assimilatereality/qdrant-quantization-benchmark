# Results

This directory stores benchmark output files generated by the `qdrant-benchmark benchmark` command.

## File Format

Results are saved as JSON with the following structure:

```json
{
  "baseline": {
    "avg": 54.2,
    "p50": 73.5,
    "p90": 75.3,
    "p95": 75.3,
    "p99": 75.4,
    "p99.5": 75.4,
    "p99.9": 75.4
  },
  "quantization": {
    "scalar": {
      "no_rescoring": { "avg": 60.7, "p50": 65.2, "p90": 77.6, "p95": 79.0, "p99": 80.0, "p99.5": 80.2, "p99.9": 80.3 },
      "with_rescoring": { "avg": 66.4, "p50": 65.2, "p90": 70.6, "p95": 72.0, "p99": 73.1, "p99.5": 73.2, "p99.9": 73.3 }
    },
    "binary": {
      "no_rescoring": { ... },
      "with_rescoring": { ... }
    },
    "binary_2bit": {
      "no_rescoring": { ... },
      "with_rescoring": { ... }
    }
  }
}
```

All latency values are in **milliseconds**.

## Fields

### Baseline
Latency measurements for the unquantized collection using float32 vectors.

### Quantization
Results for each quantization method tested. Each method contains two sub-results:

- **no_rescoring** — search performed using only the quantized vectors, without re-ranking against the original vectors
- **with_rescoring** — search candidates from quantized vectors are re-ranked against the original float32 vectors for improved accuracy at a small latency cost

### Percentile Keys
| Key | Description |
|-----|-------------|
| `avg` | Mean latency across all queries |
| `p50` | Median latency |
| `p90` | 90th percentile — latency 90% of queries fall under |
| `p95` | 95th percentile — common production SLO threshold |
| `p99` | 99th percentile — tail latency |
| `p99.5` | 99.5th percentile |
| `p99.9` | 99.9th percentile — worst-case latency |

## Generating Results

```bash
# Run benchmark and save results
qdrant-benchmark benchmark -c my_collection \
  --quantization scalar binary binary_2bit \
  -o results/benchmark_results.json

# Visualize saved results
qdrant-benchmark visualize -r results/benchmark_results.json -o results/report.png
```

## Notes

- This directory is tracked in git via `.gitkeep` but result files are gitignored.
- Use descriptive filenames when running multiple benchmarks, e.g. `results/10k_scalar_binary.json`.
